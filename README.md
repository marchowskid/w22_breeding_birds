# w22_breeding_birds
Supplementary GIS materials and orthophoto data for W22 island (Szczecin Lagoon, Poland)
## Related dataset

The full-resolution orthophoto and GRVI raster data for W22 island are archived and openly available on Zenodo:

> Marchowski, D. (2025). *Orthophoto and GRVI raster data from W22 island (Szczecin Lagoon, Poland)* (Version 1) [Data set]. Museum and Institute of Zoology, Polish Academy of Sciences.  
> DOI: [https://doi.org/10.5281/zenodo.17462386](https://doi.org/10.5281/zenodo.17462386)
